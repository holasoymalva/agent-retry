# Support

## Questions and usage help

Search the [documentation](https://github.com/holasoymalva/agent-retry#readme) and
[existing issues](https://github.com/holasoymalva/agent-retry/issues) first. If the answer is not
there, open a
[support question](https://github.com/holasoymalva/agent-retry/issues/new?labels=question).

Include your Agent Retry package versions, Node.js version, operating system, relevant
configuration, and a minimal reproducible example. Remove API keys, prompts, credentials, and other
sensitive data.

## Bugs and feature requests

Use the repository's issue forms:

- bug reports should include deterministic reproduction steps;
- feature requests should explain the recovery problem and proposed behavior.

## Security

Do not report vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub's
private vulnerability reporting flow.

This open source project provides community support on a best-effort basis. No response-time or
service-level agreement is guaranteed.
