# Security policy

## Supported versions

Until the first stable release, security fixes are provided for the latest published `0.x`
version only.

## Reporting a vulnerability

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/holasoymalva/agent-retry/security/advisories/new).
Do not disclose the issue publicly until a fix is available.

Include:

- the affected package and version;
- impact and attack preconditions;
- reproducible steps or a proof of concept;
- any suggested mitigation.

You should receive an acknowledgement within seven days. The maintainers will coordinate validation,
remediation, disclosure, and credit with the reporter. Reports made in good faith will not be
penalized.
